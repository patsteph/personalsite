# Deprecated Files

This directory contains code that is no longer used in production. These files are kept for reference but could be safely removed.

## Categories

- **API Debugging**: Test endpoints and debugging tools that were used during development
- **Client vs Server**: Duplicate implementations that were used to troubleshoot API issues
- **Legacy HTML Admin**: Old HTML-based admin interfaces that were replaced with React components
- **Testing Utilities**: Tools used for testing that aren't needed in production

These files have been moved here as part of the codebase cleanup to improve maintainability and security.
